09.Workflow vs Agent 스펙트럼
2장 · 에이전트의 구성 요소 · 2.3 챗봇과 에이전트 — 운영 관점의 차이
정의의 경계가 모호하면 이후의 설계 결정이 일관성을 잃습니다
챗봇은 1회 응답, 에이전트는 종료 조건까지 반복
챗봇 / 단일 LLM 호출
  • 입출력은 1회 응답으로 종료
  • 외부 시스템 접근 없음 (도구 호출 없음)
  • 상태는 대화 컨텍스트에 한정
  • 다음 행동은 사용자가 지시
에이전트
  • 종료 조건에 도달할 때까지 루프 반복
  • 도구를 통해 외부 시스템과 상호작용
  • 명시적 상태(State)를 영속화
  • 다음 행동을 자가 결정
판정 원칙   네 요소가 모두 갖춰진 시스템을 운영 가능한 에이전트로 본다. 빠진 요소가 있다면 그것이 곧 다음 설계 과제가 된다.

Loop

State

상태 · 기억

  • 실행 궤적(trajectory)을 영속화
  • 중단 후 재시작 가능한 형태로 보관
Policy

제약 · 가드

  • 한도 · 권한 · 중단 조건
  • 예산 한도, 도구 허용 목록
