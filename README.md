# AI 에이전트 아키텍처 — 강의 자료

기존 아키텍트 → AI 아키텍트 책임 확장을 위한 2시간 강의 자료.

## 디렉터리

```
slides/
├─ lecture/                       # 본 강의 자료 (현재 작업본)
│  ├─ 01-curriculum.md            # 커리큘럼
│  ├─ 02-architecture-canvas.md   # 캔버스 (단일 진실 원천)
│  ├─ 03-guide.md                 # 산문 가이드 (강의 후 자율 학습)
│  ├─ 04-slides.html              # 슬라이드 (39장, SK AX 톤)
│  ├─ REVIEW.md                   # 5축 검증 보고서
│  └─ assets/sk-ax-tokens.css     # 디자인 토큰
├─ slides/                        # 이전 작업 자료 (RAG · Gateway · Agent 1차본)
└─ .claude/skills/                # Claude Code 커스텀 skill 8종 (다른 PC에서 이어 작업용)
```

## 사용

브라우저에서 `lecture/04-slides.html` 열기. 화살표·스페이스로 페이지 이동.

## 다른 PC에서 이어 작업

1. 본 레포 clone
2. `lecture/REVIEW.md`로 현재 상태 확인
3. `.claude/skills/` 가 자동 로드 — `lecture-orchestrator` 등 8개 skill 사용 가능
