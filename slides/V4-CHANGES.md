> v3는 그대로 보존. v4는 v3 복사본에 비파괴적으로 2장 신설 + 인라인 3건 보강.

## 왜 v4인가 — 진단 요약

v3는 분류·의사결정 체계(정의 → 스펙트럼 → 패턴 → 4요소 → 6원칙 → 사례/실패 → 트렌드)가
**업계 평균 이상으로 완결**되어 있으나, "에이전트를 상세히 다루는 모듈" 기준에서 두 개의 구조적 공백이 있었다.

1. **메커니즘 부재** — 4요소(Loop·Tools·State·Policy)를 *정의*만 하고, 한 턴이 실제로 어떻게 도는지
   (컨텍스트에 무엇이 담기고 → LLM이 무엇을 반환하고 → 런타임이 무엇을 하는지)를 한 번도 보여주지 않음.
2. **시스템 뷰 부재** — 주제별 다이어그램은 있으나 계층을 한 프레임에 배치한 레퍼런스 아키텍처가 없음.
   `slides/section-1-rag.html`·`section-2-gateway.html` 등 시리즈 파일이 이미 존재하는데,
   RAG·AI Gateway가 전체 그림의 어느 계층인지 연결하는 슬라이드가 없어 시리즈 연결 조직이 빠져 있었다.

## v4에서 한 일

### 신설 슬라이드 (v3 디자인 시스템 그대로 — mermaid 미사용, col-card·module-flow·mini-grid)
- **2.6 「한 턴의 해부」** (신규, CH2) — ① 컨텍스트 윈도우 구성(시스템프롬프트+도구스키마+이력+직전결과)
  → ② LLM의 `tool_use` JSON 반환 → ③ 런타임 동작(검증·게이트·실행·궤적갱신·종료판정).
  각 부분을 Loop·Tools·State·Policy에 라벨링해 2.5의 "정의"를 "동작"으로 격상.
- **「종합 · 레퍼런스 아키텍처」** (신규, CH5 뒤·마무리 앞) — 6계층 `module-flow` 배치도
  (모델접근·런타임·도구·상태메모리·관측평가·HITL) + **RAG=지식도구층 / AI Gateway=모델접근층**을
  점선·오렌지로 표시해 시리즈 지도 역할. 오늘 그림 위에 두 층을 얹으면 시리즈가 완성됨을 명시.

### 인라인 보강
- **4.8 실패 사례(Replit)** — 교훈에 멱등성·보상 트랜잭션 추가(재시도·중복 호출이 두 번의 부작용이 되지 않도록).
- **4.6 관측·재현** — Eval 카드에 LLM-as-Judge 한계(자기편향·판정불안정·비용, 골든셋·사람표본 병행) 추가.
  (v3에 이미 trajectory·golden/adversarial set가 있어 나머지는 유지.)
- **3.7 Multi-Agent** — "자주 보는 함정"에 정량 배지 "비용 ≈ 15배"(Anthropic, 2025-06) 추가.
